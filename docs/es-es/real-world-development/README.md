Explora GitHub Copilot a lo largo del ciclo de vida del desarrollo de software mediante escenarios realistas, una aplicación completa y una lista de trabajo compartida. Trabajarás de forma iterativa para planificar cambios, crear código, probar el comportamiento, revisar solicitudes de incorporación de cambios y gestionar el trabajo con agentes.

## Escenario

Eres un nuevo desarrollador de Tailspin Toys, una empresa ficticia que ofrece financiación colectiva para juegos de mesa con temática de desarrollo. El trabajo pendiente de tu equipo ya está registrado como incidencias de GitHub y listo para que te ocupes de él. Incluye funcionalidades como el filtrado y la paginación, además de mejoras de calidad relacionadas con la accesibilidad y los estándares de código.

## Elige tu entorno

GitHub Copilot te acompaña dondequiera que trabajes. Elige el entorno que mejor se adapte a tu forma de desarrollar. Cada taller empieza con su propia configuración y utiliza el escenario compartido de Tailspin Toys.

### [GitHub Copilot CLI][cli]

Usa el asistente con agentes desde el terminal. Trabaja con los modos Plan y Autopilot, instrucciones, habilidades, agentes personalizados, Playwright MCP, Agent Merge y prácticos comandos de barra.

### [Aplicación GitHub Copilot][app]

Ejecuta sesiones de agente en paralelo, cambia de modo de sesión, colabora con lienzos y gestiona incidencias y solicitudes de incorporación de cambios de GitHub desde la aplicación de escritorio.

### [Agente de GitHub Copilot en la nube][cloud]

Asigna incidencias de GitHub a un agente asíncrono, guía su trabajo, supervisa su progreso y revisa las solicitudes de incorporación de cambios que abre.

### [Visual Studio Code][vscode]

Usa GitHub Copilot en Visual Studio Code y GitHub Codespaces. Trabaja con el modo de agente de Copilot Chat, servidores MCP y agentes personalizados sin salir del editor.
